# Shopping App (React useState Lab)

## Project Overview
This is a simple React shopping application built using the useState hook.  
The application includes dark mode functionality, product filtering by category, and a basic shopping cart system.

---

## Features

### Dark Mode Toggle
Users can switch between light and dark mode.  
The interface updates based on the selected theme.

### Category Filtering
Products can be filtered by category:
- Fruits
- Vegetables
- Dairy
- All

### Add to Cart
Users can add products to a shopping cart.  
The cart displays all selected items.

---

## Concepts Used
- React functional components
- useState hook
- Event handling
- Conditional rendering
- Array methods (map and filter)
